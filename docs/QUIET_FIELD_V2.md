# Quiet Field V2

**Status:** Design exploration (Living Calm V1)  
**Parent:** [LIVING_CALM_V1.md](LIVING_CALM_V1.md)  
**Supersedes for exploration only:** Quiet Field as described in Visual System V1 — *not* a production replacement

---

## Why V2

In Visual System V1 / Trust V1, the Quiet Field is a strong **landing and status motif**: deep pine atmosphere, horizon breath, soft account points, ambient pulse.

V2 promotes the Quiet Field from motif to **primary product metaphor**.

| V1 (motif) | V2 (metaphor) |
|------------|---------------|
| Appears on landing / healthy Home tint | Structures how Home is *read* |
| Atmosphere behind content cards | Field *is* the content plane |
| Pulse as polish | Pulse as truth about background work |
| Points as decoration | Points as the account model users remember |
| Easy to remove without changing IA | Removing it collapses the product’s meaning |

**Decision:** Treat Quiet Field as the mental model users take away — “my accounts rest in a calm field Mighty tends” — not as a background texture.

**Rationale:** Memorable products own a metaphor (the vault, the desk, the feed). Mighty’s honest metaphor is a quiet field of accounts, not a control tower.

---

## Definition

**The Quiet Field** is a calm atmospheric plane where:

1. **Accounts** rest as steady points of presence — never surveillance eyes.
2. **Mighty’s work** is ambient motion *beneath* the field — soft pulse / horizon breath.
3. **Stillness** means success when nothing needs the user.
4. **Attention** is a single warm signal that rises from the field — one ask, not a stack.
5. **Opportunity** is a gentler lift — value waiting, not alarm.

---

## What the field communicates

| Product truth | Field expression |
|---------------|------------------|
| Watching quietly | Steady points; no blinking “monitoring” chrome |
| Working in the background | Low-amplitude pulse under the horizon |
| You’re good | Settled field; display answer above/within field |
| Something needs you | One signal rises; rest of field stays calm |
| Value waiting | Soft gold lift on one point — benefit-concrete copy elsewhere |
| Setup incomplete | Field sparse / dim points; one guided action |

## Anatomy (V2)

### Layers (bottom → top)

1. **Depth wash** — deep field (`#243B36` → mid pine). Establishes place.
2. **Horizon band** — soft atmospheric transition; the “ground” of calm.
3. **Ambient pulse** — radial breath; visible only when watching/working.
4. **Account points** — 3–12 soft marks; stable positions; no logo salad.
5. **Signal** — optional single rising cue (attention / opportunity).
6. **Answer plane** — typography sitting *in* or *just above* the field: the human-readable truth.

**Decision:** Answer typography belongs to the field composition, not to a floating white card that covers it.

**Rationale:** Cards reintroduce dashboard grammar. The field must remain the visual sentence subject.

### Account points

- Short optical marks (dots / soft discs), not provider logo walls.
- Count may hint at portfolio size without becoming a metric strip.
- Interaction (in Living Quiet Field Home): focus a point to reveal a quiet label — never a popover card stack.

### Motion grammar

| State | Motion |
|-------|--------|
| Idle / all clear | Near-still; optional 1% horizon drift |
| Working quietly | Soft pulse 4–7s cycle, low amplitude |
| Waiting on user | Pulse + one highlighted point |
| Attention | Pulse pauses; single amber rise |
| Opportunity | Gentle gold lift; no shake / bounce |
| Reduced motion | Static field; text/status only |

**Decision:** Motion encodes state machines users already understand — never “delight loops.”

---

## Where the field must appear

| Surface | V2 expectation |
|---------|----------------|
| Metaphor stage (prototype) | Full teaching composition |
| Home · Living Quiet Field | Field is the primary canvas |
| Home · Minimal Calm | Field may reduce to a thin horizon breath — still present |
| Home · Operational Calm | Field as header atmosphere; ops sit below |
| Personality / hierarchy stages | Field as shared identity glue |
| Accounts / Activity (future) | Optional; not required for V1 exploration |

**Decision:** At least a horizon remnant must survive even Minimal Calm.

**Rationale:** If calm Home deletes the field entirely, we train users that the metaphor was marketing.

---

## Explicitly forbidden (still)

- Surveillance eyes, camera shutters, “we’re watching you”
- Robot / chatbot mascots
- Neural-net / particle magic / AI sparkles
- Shield walls and fake certification badges
- Confetti, bounce, parallax hero theater
- Metric stat strips overlaid on the field
- Multiple rising signals

---

## Relationship to color & type

Quiet Field V2 inherits Trust / Visual System warmth (stone pages, pine accent, Fraunces for the calm answer, Plus Jakarta for ops).

**Decision for Living Calm prototype:** Intensify *field occupancy* (more of the viewport is field) rather than inventing a new palette.

**Rationale:** Memorability comes from composition and ritual, not from rebranding color. A new palette would confuse comparison with Trust V1.

---

## Anti-patterns specific to V2

| Anti-pattern | Why it fails |
|--------------|--------------|
| Field as a rounded media card inset | Reads as illustration, not product space |
| White content card covering 80% of field | Metaphor becomes wallpaper |
| Points that look like a chart | Users think analytics, not presence |
| Constant aggressive pulse | Anxiety; “something’s always wrong” |
| Field only on marketing | Split personality vs app |

---

## Success criteria

1. A reviewer can explain Mighty using the field metaphor without seeing the docs.
2. Stillness feels intentional — not an empty state.
3. One rising signal is unmistakable; a second would feel like a bug.
4. Living Quiet Field Home feels like a different *product ritual* than a card Home — not a skin.
